# Code of Conduct

## Our Standards

We want Tekst to be a welcoming and respectful project for everyone.

When participating in this project, please:

* Be respectful and considerate
* Give constructive feedback
* Respect different opinions and approaches
* Focus on the project and the code
* Help others when possible
* Keep discussions relevant and professional

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination
* Personal attacks or insults
* Trolling or intentionally disrupting discussions
* Sharing inappropriate or offensive content
* Publishing someone's private information without permission
* Any other behavior that would make the project unsafe or unwelcoming

## Pull Requests and Issues

Please make sure issues and pull requests are relevant to Tekst.

When submitting a pull request:

* Explain what you changed
* Explain why the change is needed
* Test your changes when possible
* Be open to constructive feedback
* Keep changes focused and understandable

## Enforcement

Project maintainers may remove, edit, close, or reject content that violates this Code of Conduct.

Repeated or serious violations may result in restrictions on participation in the project.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please contact the project maintainer privately through the contact information available on the project website or GitHub profile.

Please do not create a public issue for sensitive reports.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, discussions, and other project-related interactions.

By participating in the Tekst project, you agree to follow this Code of Conduct.
